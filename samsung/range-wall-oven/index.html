Códigos de error de Samsung cocinas y hornos

Las cocinas Samsung muestran un código de dos partes (E-08, E-0A, E-27) para el horno y códigos cortos (SE, tE, LE) para el panel de control. La mayoría son un sensor, el bloqueo de puerta o una tecla atascada.

Cómo leer el registro de errores almacenado

Los hornos Samsung no tienen un registro de errores accesible para el usuario. El código permanece en la pantalla hasta que corriges la causa o cortas la corriente en el disyuntor durante 3 minutos; si reaparece tras el reinicio, tómalo como real.

Los menús de servicio están pensados para técnicos. Leer el registro no daña la máquina; no modifique los valores de calibración.
