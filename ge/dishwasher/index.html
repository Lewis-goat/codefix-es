Códigos de error de GE Appliances lavavajillas

Los lavavajillas GE muestran códigos C para averías de desagüe, llenado y calentamiento, H2O para falta de agua, y 888 o CFE para la placa. GE no tiene una lista oficial.

Cómo leer el registro de errores almacenado

En la mayoría de los lavavajillas GE, mantén pulsado Start durante 5 segundos con la puerta abierta para entrar en el menú de servicio; en los modelos con pantalla oculta, pulsa Select Cycle y Start a la vez durante 5 segundos. El último error se muestra en la pantalla. Corta la corriente en el disyuntor durante 60 segundos para reiniciar la placa.

Los menús de servicio están pensados para técnicos. Leer el registro no daña la máquina; no modifique los valores de calibración.
