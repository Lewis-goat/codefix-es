Códigos de error de Breville / Sage Oracle

32 códigos. La Oracle tiene doble caldera de acero inoxidable más cabezal del grupo calentado; la mayoría de los códigos corresponden a una de sus sondas de temperatura, una avería de nivel de agua o de flujo, o al molinillo.

La Oracle BES980 usa la misma tabla de 32 códigos que la Oracle Touch BES990. En pantalla muestra «Error 15» en lugar de «ER15».

Cómo leer el registro de errores almacenado

Deja la máquina enchufada pero apagada. Pulsa y mantén a la vez 1 CUP, 2 CUP y POWER durante al menos un segundo. Tras el pitido largo, la pantalla LCD muestra la versión de firmware (empieza por «Fr»). Pulsa una vez el dial SELECT para abrir Error Storage y luego gíralo para recorrer los errores 1 a 32 y el recuento almacenado de cada uno. Desplázate más allá del error 32 hasta «ErSt» y mantén SELECT 3 segundos para borrar el registro.

Los menús de servicio están pensados para técnicos. Leer el registro no daña la máquina; no modifique los valores de calibración.
